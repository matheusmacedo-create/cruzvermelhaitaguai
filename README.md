# cruzvermelhaitaguai.org

Página inicial provisória do domínio, hospedado na Hostinger. Existe para o
domínio responder (sem ela a Hostinger devolve 403) e para carregar a metatag
`facebook-domain-verification` da verificação do domínio no Gerenciador de
Negócios do Facebook (BM). Não remova a metatag: o Meta volta a conferir o
domínio periodicamente e a verificação cai se ela sumir.

## Publicar

Enviar `index.html` para a pasta `public_html` do domínio no hPanel
(Gerenciador de Arquivos) ou pela implantação via Git da Hostinger
(Avançado → Git), apontando para este repositório.
